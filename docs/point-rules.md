# ポイント加算ルール

Math Mapでポイントが加算される条件の一覧です。点数の重みを見直すときの基準として、現在の実装値を記録しています。

## 現在の加算条件

| 区分 | 条件 | ポイント | 加算単位・補足 |
| --- | --- | ---: | --- |
| 共通 | 本日の初回学習 | +5 pt | 1日につき1回 |
| 共通 | 新しい単位に着手 | +1 pt | 問・節・ページ・項目の1単位、1周につき初回 |
| 演習 | 問題を解決 | +2 pt | 1問・1周につき初回。自力で解決した場合と、解答を見て解決した場合の両方が対象 |
| 読書 | 読書単位を読了 | +5 pt | 節・ページ・項目の1単位、1周につき初回 |
| 共通 | 章を完了 | +15 pt | 「読む」「演習」の各トラック、各周の章ごと |
| 共通 | 教材を100%完了 | +50 pt | 「読む」「演習」の各トラック、各周ごと |
| 継続 | 連続学習 | 下表参照 | 各到達日数につき1回 |
| 継続 | 学習再開 | +5〜20 pt | 前回の学習後に3日以上の空白があった日の初回学習時 |
| 目標 | 日次目標を完了 | +10 pt | 同じ日に学習記録3件かつ完了記録2件を達成 |
| 目標 | 週間達成目標を完了 | +50 pt | 週内のスコアが100以上。学習記録は1、完了記録は3として集計 |
| 報酬 | 時限達成報酬を受領 | +15 pt | 5単位を初回完了するたびに発生。3時間後から24時間以内に受領 |

### 連続学習ボーナス

| 到達日数 | ポイント |
| ---: | ---: |
| 3日 | +3 pt |
| 7日 | +10 pt |
| 14日 | +25 pt |
| 30日 | +60 pt |
| 60日 | +150 pt |
| 100日 | +300 pt |

### 学習再開ボーナス

| 学習しなかった日数 | ポイント |
| ---: | ---: |
| 3〜6日 | +5 pt |
| 7〜13日 | +10 pt |
| 14日以上 | +20 pt |

## 重複加算について

同じ記録に対するポイントは重複して加算されません。単位の着手・完了、章完了、教材完了などは、教材・トラック・周・対象単位を組み合わせた識別子で管理しています。

複数の条件を同時に満たした場合は、それぞれのポイントが加算されます。たとえば、その日の最初の問題で新しい単位に着手した場合は「本日の初回学習」と「新しい単位に着手」の両方が対象です。

## 現在の読書・演習の重み

読書単位の読了は **+5 pt**、問題の解決は **+2 pt** です。1節の読書に約3時間、1問の演習に約10〜60分かかる想定をもとに、読書のほうを2.5倍の重みにしています。章完了と教材完了については、「読む」と「演習」で同じ点数です。

以前に記録した読了ポイントも、保存データを読み込む際に **+5 pt** へ更新されます。問題解決やその他の加算記録は変更されません。

この文書は現行仕様の記録です。ポイント値を変更した場合は、アプリ内の「目標・実績 → ポイントの加算条件」とこの文書を同時に更新してください。
