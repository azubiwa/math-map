# Math Map

数学の演習進捗を、教材・章・問題ごとに記録して可視化する個人用Webアプリです。

## 主な機能

- 教材、章、問題数の登録・編集
- 問題ごとの学習状態と復習キュー
- 日別ヒートマップ、週間・月間目標、連続学習日数
- マイルストーンと試験モード
- 教材の並べ替え、アーカイブ、復元
- JSONバックアップの書き出し・読み込み
- ダークモード

データはブラウザのローカルストレージに保存されます。

## 開発

```sh
npm install
npm run dev
```

確認用コマンド：

```sh
npm test
npm run build:pages
```

`main` ブランチへのpushでGitHub Pagesが自動更新されます。
